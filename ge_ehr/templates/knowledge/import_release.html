  1. Validate. The file must be a GRCh38 ClinVar-format VCF; GRCh37 files are refused, and the same file (by SHA-256) can be imported only once.
  2. Store. Records in GCK, HNF1A, HNF4A, HNF1B, KCNJ11, ABCC8 and INS become a new, inactive release. Files marked ##ge_ehr_synthetic=true are flagged as synthetic.
  3. Activate (now, or later from the release page). Only the {{ stored_keys|number }} stored patient variant {{ "key is" if stored_keys == 1 else "keys are" }} compared with the current release; the carriers of each changed key are re-evaluated:
    • {{ kb.category_badge("upgrade") }} new alerts, flagged Reclassified, high priority, clinicians notified
    • {{ kb.category_badge("downgrade") }} alerts superseded and a review notice raised — therapy is never reversed automatically
    • {{ kb.category_badge("within_actionable") }} {{ kb.category_badge("within_non_actionable") }} provenance updated, no notification
  4. Log. Every activation is recorded as a re-evaluation run with its counters, so the state before and after stays reproducible.
